# Звуки «ОАЗИСА» v0.9.0

Все 13 звуков в этой папке созданы алгоритмически для проекта без использования сторонних записей и аудиосэмплов. Нет музыки, голосов, мелодий, звуков животных.

| Файл | Назначение |
|---|---|
| `wind.mp3` | Циклический пустынный ветер |
| `water_ambience.mp3` | Циклическое журчание воды |
| `plant.mp3` | Посадка / почва |
| `water.mp3` | Полив и колодец |
| `harvest.mp3` | Сбор урожая |
| `build.mp3` | Постройки |
| `canal.mp3` | Строительство арыка |
| `coin.mp3` | Продажа на базаре |
| `click.mp3` | Интерфейс |
| `upgrade.mp3` | Улучшение хозяйства |
| `collect.mp3` | Получение продукции |
| `error.mp3` | Ошибка действия |
| `quest.mp3` | Награда за задание |

Создано генератором `tools/generate_audio.py` (NumPy/SciPy + ffmpeg, фиксированная случайная последовательность). В интернете никакие аудиофайлы не скачивались. Дорожки представляют собой синтетические приближения к природным/механическим звукам, а не полевые аудиозаписи.

Формат: MP3, 24 kHz, 56 kbit/s, mono. Аудио сохраняется локально в составе игры и работает без аудиосервера после загрузки страницы. Phaser CDN для самой игры по-прежнему требует подключения к сети, если не закеширован.
