# Обновление до 3.1.0

Перед обновлением сохраните файл игры: главное меню → Настройки → Сохранить файл игры.

Распакуйте архив. Загрузите **содержимое** папки `oasis-game-mobile-v0.2` в ту же папку репозитория GitHub Pages, где сейчас находится игра, с заменой файлов. Сам репозиторий удалять не нужно. URL Mini App оставьте прежним.

После завершения публикации полностью закройте Mini App и откройте заново. Номер версии — 3.1.0. В полноэкранном компактном HUD номер скрывается ради места; версия также указана в этом файле.

Не очищайте данные браузера: в них находится прогресс и родительский контроль. Обновляйте на прежнем адресе и устройстве. Архив не включает тестовую ферму или чужое сохранение.

Перед массовым обновлением проверьте на Android и iPhone: запуск с меню, верхнюю панель рядом с кнопками Telegram, закрытие дома, рынок, посадку рядом с арыком и размер дома. Намазы требуют загрузки проверенной таблицы — см. PRAYER_SCHEDULE.md.
