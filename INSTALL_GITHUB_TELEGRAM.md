# Обновление до 2.3.0

1. Сохрани копию текущих файлов репозитория. Репозиторий и GitHub Pages удалять не нужно.
2. Распакуй ZIP. Внутри прежняя папка oasis-game-mobile-v0.2.
3. Замени содержимое существующей папки игры файлами из этой папки. Если index.html уже лежит в корне репозитория, загружай содержимое папки туда, без дополнительного вложенного каталога. Загрузи весь комплект, включая assets/art/v2.2, assets/art/v2.3, js и css.
4. Дождись успешной публикации GitHub Pages. Адрес сайта и адрес Mini App в Telegram оставь прежними.
5. Полностью закрой Mini App и открой снова. На экране должно быть v2.3.0. При старой версии перезагрузи страницу приложения; данные приложения и localStorage не очищай — там прогресс.
6. Открой «Продолжить игру». Колодец получает площадку 3×3. Если рядом занято, подбирается свободное место; посадки и запасы не удаляются.

Для проверки на телефоне: поверни экран; открой журнал и торговую площадь; попробуй масштаб двумя пальцами, перенос растения и канала; закрой и снова открой Mini App. Синтетические жесты проверены в Chromium, но реальные Android/iOS требуют проверки владельцем.

Не загружай ZIP как единственный файл сайта: GitHub Pages нужен распакованный index.html и папки ресурсов. Отдельных файлов больше 25 МБ в сборке нет. Удалять старые ассеты необязательно: игра загружает нужные по явным адресам; ссылки на JS/CSS имеют новую версию.
