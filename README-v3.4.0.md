# ОАЗИС 3.4.0 — тестовая сборка

В этой сборке подключены 30 одобренных вариантов графики, включая исправленные загоны, и 12 обработанных звуков из последнего согласованного пакета. Предыдущие звуки сохранены. Публикация в бета не выполнялась.

## Изменения
- Равномерный масштаб зданий с точками привязки из утверждённого каталога. Входы слева/справа, предпросмотр разворота и переноса.
- Участки с запасом: обычные постройки 5×5, дом 7×7, загон 5×7/7×5, колодец 4×4. Грядки 2×2 сохранены.
- Перенос старых сохранений с сохранением монет, запасов, уровней и времени производства. Если места для здания нет, оно остаётся в сохранённых постройках. Перед первым обновлением создаётся локальная резервная копия `oasis_before_v34`.
- Монеты справа напротив меню, четыре кнопки вертикально, безопасные верхние отступы Telegram, один крестик в списке построек.
- Обучение: 8 выбираемых глав, небольшая перемещаемая по свободным зонам подсказка, подсветка без затемнения всей игры, переход по выполненному действию. Можно пропустить шаг или прервать главу.
- Звуки каналов, строительства, производства, кормления, молока, шерсти, заданий работнику, удаления, ошибок и предупреждений времени. Голосовые записи ещё не добавлены.

## Запуск
Разместить содержимое папки на HTTP(S)-хостинге вместе с `index.html`, `js`, `css`, `vendor`, `assets`. Все игровые ресурсы локальные; Telegram SDK используется при запуске внутри Telegram.
Для локальной проверки: `python3 -m http.server 8000`, затем открыть `http://localhost:8000/`.
Для сохранения существующего прогресса обновлять игру на прежнем адресе и в прежнем браузере/Telegram.

## Озвучка
`tutorial-voice-map.json` содержит стабильные идентификаторы реплик и текущий черновой текст. После согласования сценария текст можно изменить без изменения идентификаторов. Разместить записи в `assets/audio/voice/` и заполнить `js/core/Narration34.js`. Пустая таблица не вызывает загрузку несуществующих файлов; обучение полностью работает текстом.

## Проверка
Пройдены проверки модели, благотворительных обращений, аудиосистемы, геометрии всех 30 вариантов при двух разворотах и трёх масштабах, миграции всех 21 производственных вариантов и логики обучения.
Полноценный браузерный запуск в среде сборки недоступен. Тест DOM старого набора требует отсутствующий пакет linkedom. Эти проверки не объявлены пройденными.
Остаётся ручная проверка в Telegram на iPhone и Android: реальные безопасные отступы, клавиатура в торговле, положение подсказок относительно всех окон, визуальное сопряжение старых грядок/каналов с новыми зданиями. Текст обучения предварительный до согласования озвучки.
