# Графика «ОАЗИС» v1.0.0

15 оригинальных PNG-спрайтов созданы специально для этого проекта из геометрических векторных форм. Лица, тела людей и животных отсутствуют.

- По две стадии для каждой из шести культур: `*-grow.png`, `*-ripe.png`.
- `well.png` — центральный колодец.
- `building-sheep.png` — закрытый шатёр; животных не видно.
- `building-camel.png` — закрытый глиняный загон; животных не видно.

PNG загружаются через `LoadingScene.js`, карта отображает их через `MainScene.renderArtwork`. При пропаже спрайта применяется процедурный запасной вариант.

Воспроизводимый генератор исходных форм: `tools/generate_art.py` (для разработчика нужны Python, CairoSVG, Pillow). Запуск самой игры никаких Python-библиотек не требует.
