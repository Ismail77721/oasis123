# ОАЗИС 3.1.0 — сборка для тестирования

## Изменения
- Семейный дом увеличен с 4×4 до 8×8 клеток вместе со спрайтом всех уровней. Грядки остаются 2×2. При обновлении ищется ближайшее свободное место; если его нет, дом сохраняется и увеличение ждёт расширения территории. Урожай, монеты и постройки не удаляются.
- Убран ошибочный множитель дальности орошения. Лопата 1–3 орошает один ряд грядок с каждой стороны канала, 4–6 — два, 7–10 — три. Проверяется вся грядка, а не только её начальная клетка.
- Верхняя панель привязана к верхней безопасной границе экрана. В полноэкранном Telegram зарезервированы места под его кнопки. Убрано повторное прибавление верхнего отступа Telegram к HUD.
- Боковые кнопки квадратные, подписи переносятся; на коротком экране кнопки располагаются в два столбца. Значок меню теперь SVG.
- Окна выше кнопок работника и журнала; у дома доступная кнопка закрытия. Уменьшены шрифты окон и исправлены внутренние отступы.
- Главное меню видно сразу из HTML, элементы фермы скрыты до завершения подготовки. При сбое/долгой загрузке предлагается повторить загрузку.
- Очищен спрайт доски заказов, убраны тесные плашки под названиями торговых мест.

## Намазы: что работает
Настройки → Родительский контроль → PIN → Намазы.
Функция выключена по умолчанию. Можно загрузить JSON расписания города, включить напоминания за 15/30 минут и выбрать только напоминание либо перерыв 40/60 минут. Используется часовой пояс из таблицы. Время выбирается по текущей календарной дате; закрытие/открытие игры не сбрасывает перерыв. Урожай и производство продолжаются. Перерыв не расходует дневной лимит игры. Общий потолок 4 часа сохранён.

Если на сегодня нет данных, перерыв не запускается, в меню появляется предупреждение. Напоминания работают внутри открытой игры, системных push-уведомлений нет.

**Не реализовано:** автоматическая загрузка городов и расписаний с Tawkit. Публичный API и возможность стабильного использования его базы в другой игре пока не подтверждены. База Tawkit и код приложения не включены в архив. В этой сборке есть рабочий механизм с загрузкой проверенной таблицы; это не законченная автоматическая интеграция Tawkit.
Формат и порядок подключения: PRAYER_SCHEDULE.md. Потребуется фактическое расписание выбранного города/мечети, после чего его можно подготовить для загрузки.

## Проверено
- Автоматические тесты модели: сохранение имущества при миграции, размеры участков, орошение с двух сторон, работник, PIN и дневной лимит.
- Тесты намазов: валидация таблиц, часовой пояс, границы напоминания/перерыва, переход через полночь, отсутствие даты и отключение функции.
- Тест DOM со всеми игровыми скриптами и имитацией Phaser: запуск меню, дом, вход по PIN, доступность настроек намазов, блокировка/разблокировка и новый спрайт рынка.
- Проверка синтаксиса JS и существования локальных файлов ресурсов.

**Ограничение проверки:** итоговая сборка не прошла визуальную проверку в Telegram на реальных Android/iPhone. Встроенный браузер предпросмотра оказался недоступен. Раскладку с системными кнопками Telegram нужно подтвердить на телефонах. DOM-тест не заменяет проверку рендера Phaser и внешнего вида.

Звуки из запрошенного списка пока не добавлены: ожидаются выбранные аудиофайлы.
