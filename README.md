# ОАЗИС — v1.9.1 (спрайты встроены)

Игра для GitHub Pages / Telegram Mini App. Имя корневой папки внутри ZIP **oasis-game-mobile-v0.2** — не переименовывать.

**Установка:** скопируйте всё содержимое ZIP в существующую папку игры на GitHub. Если GitHub Pages показывает старый визуал — сделайте полную перезагрузку страницы или очистите кеш сайта. Все относительные пути работают под подпапкой GitHub Pages.

**Новое:** 53 прозрачных изображения и новая отрисовка растений, деревьев, каналов, забора, строений и рыночной площади. Главные кнопки переведены со стандартных эмодзи на собственные иконки. Уровни не ограничены числом 20. Основные ресурсы/сохранения совместимы со старыми версиями.

**Контактный лист:** `docs/SPRITE_CONTACT_SHEET.jpg`; отдельные файлы: `assets/sprites/`; код рендера: `js/scenes/SceneV200.js`.

**Тесты:** `node tests/v1_9_1_sprite_integration.cjs` и `node tests/*.cjs` (запускать отдельно). Проверки Node пройдены, но браузер с настоящим Phaser и физический телефон пока не проверены.

**Ограничения:** стадии роста пока временные цветовые варианты зрелых изображений; для некоторых производств и старших уровней дома отдельные спрайты ещё нужны.
