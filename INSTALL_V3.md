# Обновление GitHub Pages и Telegram

1. Сохрани резервную копию действующего проекта и игрового прогресса.
2. Распакуй ZIP. Внутри сохранено прежнее имя папки: `oasis-game-mobile-v0.2`.
3. Загрузи СОДЕРЖИМОЕ этой папки в ту же папку репозитория, где сейчас лежит index.html игры, с заменой файлов. Не создавай дополнительную вложенную папку и не удаляй репозиторий.
4. Дождись успешного завершения развёртывания GitHub Pages.
5. Закрой Mini App полностью и открой снова. В правой части панели должна появиться версия v3.0.0. Если осталась старая версия, обнови страницу; не очищай данные игры, чтобы не потерять сохранение.
6. При сохранении прежнего адреса страницы URL Telegram Mini App менять не нужно.

В архиве нет тестовых профилей и заполненных ферм. На новом устройстве начинается обычная новая игра, на прежнем читается прежнее сохранение `oasis_save_v1`.

Локальный запуск: открой терминал в папке игры и выполни `python3 -m http.server 8000`, затем открой http://localhost:8000. Для PIN требуется безопасный контекст: localhost либо HTTPS. GitHub Pages использует HTTPS.

Проверки модели (если установлен Node.js): `node tests/v3_model.cjs`.
