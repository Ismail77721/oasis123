# Установка ОАЗИС 2.1.0

1. Сохрани копию нынешних файлов репозитория. Если в игре доступен экспорт сохранения, сделай резервную копию своего хозяйства. Не очищай данные браузера/Telegram.
2. Распакуй ZIP. Внутри одна папка `oasis-game-mobile-v0.2`.
3. Открой в GitHub ту папку, где сейчас лежит рабочий `index.html`. Замени её содержимое содержимым папки из ZIP: index.html, js, css, assets, vendor и остальные файлы. Не помещай новую папку внутрь прежней ещё одним уровнем. Сам репозиторий удалять не нужно.
4. Обязательно загрузи всю `assets/art/approved`, включая manifest.json, и новые скрипты. ZIP сам по себе GitHub Pages не запускает — нужны распакованные файлы.
5. Сохрани изменения и дождись завершения существующей публикации Pages. Адрес страницы и URL Mini App оставь прежними.
6. Полностью закрой Mini App и открой снова. Вверху должно быть `v2.1.0`. Если видишь старую версию, сначала проверь завершение публикации и расположение index.html; не удаляй сохранение ради очистки кэша.

Ключ сохранений остаётся `oasis_save_v1`. Он локальный: Safari, другой браузер и Telegram могут иметь разные хранилища. Эта сборка не переносит сохранение автоматически между приложениями и устройствами.
Для локального запуска: HTTP-сервер из папки игры, например `python3 -m http.server 8000`, затем http://localhost:8000/. Открытие index.html двойным нажатием через file:// не подходит для загрузчика Phaser.

Что изменено, фактические проверки и оставшиеся задачи: docs/RELEASE_v2.1.md. Это версия для проверки владельцем, не заявление об окончательной готовности всей игры.
