Для запуска используйте HTTPS-хостинг либо локальный HTTP-сервер; не открывайте index.html через file://.

Инструкция: INSTALL_V3.2.md.
Изменения и границы проверки: RELEASE_V3.2.md.
Автоматические проверки: tests/README_V32.md.

Прогресс сохраняется локально на устройстве. Верхний предел времени игры — четыре часа в сутки; меньший лимит настраивается в родительском контроле.
