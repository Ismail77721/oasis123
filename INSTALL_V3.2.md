# Обновление до ОАЗИС 3.2.0

1. Распакуйте архив.
2. Замените файлы игры содержимым папки oasis-game-mobile-v0.2 на прежнем адресе размещения. Важно заменить index.html, js, css и assets вместе: смешивание версий вызывает ошибки.
3. Старые файлы js/core/PrayerV310.js и js/scenes/PrayerInterfaceV310.js больше не нужны. Новый index.html их не загружает.
4. Дождитесь завершения обновления сайта, полностью закройте Mini App и откройте снова.

Не очищайте данные браузера и не меняйте адрес игры: локальный прогресс и PIN хранятся на устройстве. Архив содержит код и ресурсы, без тестовых сохранений. Перед обновлением сохраните копию файлов прежней сборки для возможности отката.

После установки проверьте на Android и iPhone:
- сначала видно главное меню;
- кнопки Telegram не закрывают игровые элементы;
- в настройках нет раздела расписаний;
- каналы строятся узкими сегментами, соединяются с колодцем;
- «Развернуть вход» меняет дом после подтверждения;
- торговая навигация и закрытие амбара работают.

Сборка подготовлена для самостоятельного размещения. Автоматическая публикация не выполнялась.
