# Расписание намазов

В этой сборке импортируется проверенная таблица, а не рассчитываются времена по координатам. Автоматическое подключение Tawkit ещё не готово.

1. Получите фактическую таблицу у выбранной мечети/поставщика для нужного города и периода.
2. Подготовьте JSON UTF-8: `city` — название, `timezone` — часовой пояс IANA (например, Europe/Moscow), `source` — источник, `days` — объект по полным датам YYYY-MM-DD.
3. Каждой дате соответствует массив ровно пяти строк HH:MM в порядке **Фаджр, Зухр, Аср, Магриб, Иша**. Восход не включается. Время — местное для указанного города. Все пять значений должны возрастать в пределах дня.
4. Загрузите файл в родительском контроле, проверьте город и период, нажмите «Сохранить настройки намазов».

Структура (это шаблон, не расписание; замените все значения):

```json
{
  "city": "Название города",
  "timezone": "Europe/Moscow",
  "source": "Название мечети или источника",
  "days": {
    "YYYY-MM-DD": ["HH:MM", "HH:MM", "HH:MM", "HH:MM", "HH:MM"]
  }
}
```

Можно загрузить до 800 дат, файл до 500 КБ. Таблица хранится на устройстве и работает без интернета. На каждый новый день игра выбирает соответствующую строку. Если таблица закончилась, потребуется новый файл; старое время автоматически не повторяется. Для будущей автозагрузки потребуется отдельный проверенный источник данных.

После импорта сверяйте расписание со своим источником. Город не определяется по геолокации, данные никуда не отправляются. Настройки защищены тем же PIN, что и дневной лимит. Удаление данных браузера удалит и локальные настройки.
