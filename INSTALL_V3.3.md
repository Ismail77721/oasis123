# Обновление ОАЗИС до v3.3.0

Это тестовый архив; игра автоматически никуда не публиковалась.
Распакуйте `oasis-game-mobile-v0.2` и замените содержимое каталога игры на хостинге файлами из этой папки. Сохраните тот же адрес сайта, чтобы локальный прогресс остался доступен. Затем полностью закройте мини-приложение и откройте снова.
Не очищайте данные сайта: прогресс хранится на устройстве. ZIP нельзя запускать как APK; игра открывается по HTTPS через браузер или Telegram. Для локальной проверки подойдёт HTTP-сервер из каталога с index.html.

Сначала проверьте на своих телефонах: открытие меню возле кнопок Telegram, торговлю с клавиатурой, возврат на ферму, перенос и поворот дома, одиночный выбор клетки канала, вид грядок/каналов, работника в доме и звук при сворачивании.
